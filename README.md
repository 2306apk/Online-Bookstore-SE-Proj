# Online Bookstore

A web-based bookstore for browsing, searching, and purchasing books online.

## Features
- User registration and login
- Browse, search, and filter books
- Cart and wishlist management
- Checkout, payment, and order tracking
- Admin management of books, inventory, users, and orders
- Ratings and reviews

## Tech Stack
- Frontend: JavaScript (MERN Stack)
- Backend: Python (Django)
